# 定格截图 · 浏览器插件

把「截当前网页」这件事从系统级搬到浏览器里：点一下工具栏图标就截下当前标签页的可视区，
在图上拖框就只留框里那块，然后复制、存 PNG，或一键送进定格编辑台继续标注 / 取字 / 翻译。

不上传任何图片，也不申请网站数据权限——只在你点图标的那一刻，凭 `activeTab` 截当前页。

## 装

Chrome / Edge 都是同一套：

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），右上角打开「开发者模式」。
2. 点「加载已解压的扩展程序」，选仓库里的 `extension/` 目录。
3. 工具栏出现蓝色「定格」图标；没显示就点拼图图标把它钉出来。

没有构建步骤，目录里就是源码，改完点「刷新」即可。

## 用

- **截当前页**：点图标即自动截一张（内部页面、阅读模式、受保护页面不给截，会明确报错）。
- **框选裁剪**：在预览图上按住拖出一个框，松手后复制 / 保存 / 送编辑台都只输出框里那块；拖动不足 8px 视为误触，自动回到整张。点「取消框选」回到整张。
- **复制图片**：写进系统剪贴板，可以直接粘进聊天窗口、Word、PPT。
- **存 PNG**：交给浏览器下载，文件名 `stillframe-年月日-时分秒.png`。
- **送编辑台**：先把图放进剪贴板，再打开编辑台（默认线上站，可在底部改成自己的地址）。到页面里按 `Ctrl+V` 就进来了——编辑台的粘贴入口就是为这条链路加的。

## 为什么不做「全页长截图」

浏览器插件能截的是**可视区**。滚动拼接要连截十几屏再对齐重叠区，网页里固定导航条、懒加载图片、吸底工具栏都会让拼接错位，
成功率不如桌面端的自动滚动（那是注入滚轮 + 逐帧判定到底）。这条留在桌面壳做，插件不假装能做。

## 边界

- 只有 `captureVisibleTab`，所以截的是「你能看到的那一屏」，缩放比例、暗色模式按页面实际呈现来。
- 剪贴板写入在部分环境会被拒（比如系统剪贴板被别的程序长期占用）；失败时提示改用「存 PNG」。
- 送编辑台依赖剪贴板这一跳，所以浏览器要求页面有焦点后才允许粘贴——这是浏览器安全策略，不是插件的限制。
